# AuthorNotice

作者申明色块。短代码 `[notice]…[/notice]`。本目录复制到 `usr/plugins/AuthorNotice/` 后启用即可。

在 **Daydream** 下，写文章侧栏「组件插入」里可以选择预设、改颜色并预览。其它主题请手写短代码。

## 启用

1. 将本目录放到 `usr/plugins/AuthorNotice/`
2. 后台启用 **AuthorNotice**
3. 使用 Daydream 时，写文章/页面右侧会出现「组件插入」

## 短代码

```
[notice title="标题" color="#4E7289" text="#ffffff" radius="12" shadow="1"]
正文，支持空行分段与 [链接文字](/path)
[/notice]
```

插件设置可改默认背景色 / 文字色。
