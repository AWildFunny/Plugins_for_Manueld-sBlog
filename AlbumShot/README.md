# AlbumShot（图文融合）

文章里的图文画布：单图版式、多图构图、叠字、再编辑。本目录复制到 `usr/plugins/AlbumShot/` 后启用。

可视化排版需要 Daydream 写文章侧栏的 **组件插入 → 图文融合**。其它主题可手写单图短代码；多图请尽量用面板插入 HTML 画布，避免 Markdown 拆布局。与音乐相册章头搭配时，还需要 Daydream 的相册模板。

## 后台用法（1.8）

1. 右侧 **附件图片库** 以缩略图列出本文及近期图片附件（上传后可点「刷新附件库」）。
2. **点击**选用，或 **拖到左侧预览区** 投放。
3. 单图：投放后即替换主图并按版式预览；多图/画布：逐张加入画布。画框内拖动裁剪、左下角移动、右下角缩放、滚轮变焦。画幅可选预设或「自定义」（填宽:高，或拖动画布下沿）。改画幅/构图时左侧预览即时更新。
4. **添加文字**：任意分类都可点。单图会切到自由画布（已选主图会带上）；双图/多图/画布则在当前构图上叠一层文字，换构图只重排图片、不挪文字。文字框可拖动、右下角缩放、滚轮改字号，**双击编辑**；选中后可用字号/颜色/对齐/粗体/阴影。
5. 确认后点底部「插入」。插入块会写入 **历史 / 再编辑**：下次打开插件可一点加载，改完再插入会**替换正文里的原块**（也可点「改为新插入」另存一块）。旧稿没有包装注释的画布也会尽量从正文识别出来。

> 根因说明：Typecho 附件列表里 `a.insert` 的 `href` 常为 `###`，真实地址在 `li[data-url]`。旧版下拉框误用文件名，导致无法预览。

## 分类

| 分类 | 说明 |
|------|------|
| 单图 | 与章节标题的关系：横幅 / 叠字 / 分栏 / 环绕。图片按原比例，不裁切拉伸 |
| 双图 | 左右对开、主副、叠压 |
| 多图 | 一大两小、三联、四宫 |
| 自由画布 | 多图拖拽定位、缩放；坐标为画幅百分比，窄屏整页等比缩放 |

## 短代码

单图：

```
[album-shot layout="overlay" src="/usr/uploads/a.jpg" alt="现场"]
```

多图 / 画布（插入的是与前台相同的 HTML，避免 Markdown 拆图）：

```
<div class="album-board" data-ratio="3:2">...</div>
```

旧短代码仍可用：

```
[album-board ratio="3:2"][img src="https://..." x="2" y="6" w="47" h="88" ox="50" oy="40"][/album-board]
```

`x` `y` `w` `h` 为相对画幅的百分比。带 `h` 时图片在画框内 `cover` 裁剪，可用 `ox` `oy`（0–100）与 `zoom`（1–3）控制取景。无 `h` 的旧短代码仍按原比例显示。

文字层（旧短代码）：

```
[txt x="8" y="70" w="80" h="22" fs="5" color="#ffffff" align="left" weight="700" shadow="1"]现场标题[/txt]
```

`fs` 是相对画幅宽度的字号（约 1.5–16，对应 `calc(fs * 1cqw)`），前台随画布缩放。插入时仍输出 HTML，与图片层一样避免 Markdown 拆布局。

**Markdown 注意**：相邻 `[...][...]` 会被解析成引用链接。组件插入会自动包一层 `<div>`；手写时也请包在 HTML 块内。从 1.1 升到 1.2 后请在后台对 AlbumShot **禁用再启用**，以注册 Markdown 保护钩子。
